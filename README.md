## 📖 Key Literature Summaries (`/books`)

Each summary extracts core principles, capability models, and metrics from the respective literature:

*   **[Accelerate](file:///Users/hbakesson/Coding/sofia/books/accelerate.md)**: Establishes the link between DevOps capabilities and organizational performance using the **Four Key (DORA) Metrics** (Deployment Frequency, Lead Time, Change Fail Rate, and MTTR).
*   **[Frictionless](file:///Users/hbakesson/Coding/sofia/books/frictionless.md)**: Pivots from system metrics to developer-centric workflows, analyzing feedback loops, flow state, and cognitive load in the modern AI/Agentic era.
*   **[Accelerate vs. Frictionless](file:///Users/hbakesson/Coding/sofia/books/accelerate_vs_frictionless.md)**: A side-by-side comparative guide highlighting the evolutionary shift from DevOps systems to developer experience, with in-depth breakdowns of the **SPACE Framework** and anti-gaming guardrails.
*   **[Team Topologies](file:///Users/hbakesson/Coding/sofia/books/teams_top.md)**: Explains the application of Conway's Law to organizational design, defining the four fundamental team types (Stream-Aligned, Platform, Enabling, Complicated-Subsystem) and three interaction modes.
*   **[Software Engineering at Google](file:///Users/hbakesson/Coding/sofia/books/engineering_at_google.md)**: Captures how Google scales its engineering culture, processes (testing, code reviews, documentation), and tools over time.
*   **Other Classics**:
    *   **[Clean Code](file:///Users/hbakesson/Coding/sofia/books/clean_code.md)**: Principles of writing readable, maintainable code.
    *   **[DevOps Handbook](file:///Users/hbakesson/Coding/sofia/books/devops_handbook.md)**: Tactical implementation patterns for CI/CD, telemetry, and safety cultures.
    *   **[Fundamentals of Software Architecture](file:///Users/hbakesson/Coding/sofia/books/sw_arch_fundamentals.md)**: Analysis of architectural patterns, trade-offs, and soft skills.
    *   **[Thinking, Fast and Slow](file:///Users/hbakesson/Coding/sofia/books/thinking_fast_slow.md)**: Cognitive science framework (System 1 & System 2 thinking) applied to decision-making.
